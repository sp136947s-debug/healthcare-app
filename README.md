# NIDAN — Full VS Code Ready MVP

NIDAN is a voice-first, multilingual healthcare navigation assistant:
**Bolna → samajhna → safe guidance → next step → healthcare access.**

## Stack
- Flutter / Dart mobile app
- Python / FastAPI backend
- PostgreSQL + pgvector
- OpenAI Responses API for the AI assistant
- OpenAI embeddings for RAG
- Device speech-to-text + TTS for the MVP
- Google Places API (New) optional for nearby healthcare

## Safety boundary
NIDAN is a healthcare navigation and information assistant, not a doctor and not a diagnostic system.
It must escalate emergency symptoms and must not invent medical records, ABHA status, facilities, prices, appointments, or treatment instructions.
